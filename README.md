# Rock-vs-Mine-detection-model

A Machine Learning project that predicts whether an object detected by sonar signals is a **Rock** or a **Mine** using classification algorithms.

This project is built using **Python**, **NumPy**, **Pandas**, and **Scikit-learn**.

---

# Project Overview

Sonar systems send sound signals underwater and receive reflected signals back.  
Based on the reflected sonar data, this model classifies objects into:

- **Rock (R)**
- **Mine (M)**

The model is trained on the famous **Sonar Dataset** using supervised machine learning techniques.

---

#  Features

- Data preprocessing using Pandas

- Prediction system for custom input
- Binary classification using Machine Learning

# 📈 Model Performance

The trained Logistic Regression model achieved:

- **Training Data Accuracy:** 80%
- **Testing Data Accuracy:** 85%

The model performs well on unseen data, showing good generalization capability and minimal overfitting.
